One more step: set the shortcut

Chrome doesn't let a new extension claim ⌘⇧C on its own, because the key is already taken by DevTools' "inspect element". You can still give it to Copy URL yourself:

  1. Click the button below to open Chrome's extension shortcuts page.
  2. Find Copy URL and click the pencil next to "Copy the current tab's URL".
  3. Press ⌘⇧C.

Until then, clicking the Copy URL icon in the toolbar copies the URL too. Pin it from the puzzle-piece menu to keep it in reach.
